배지 싱크 실험 (폰 소리 + 기기 영상)

1. 기기 연결

연결 안 됨
이 브라우저는 Web Bluetooth를 지원하지 않습니다. 안드로이드 Chrome에서 열어 주세요.

2. 음원과 영상 번호

음원 파일을 고르세요. 여러 개를 한 번에 골라 두면 소리 전환 때 기기가 재생 중인 영상의 음원을 자동으로 씁니다 (파일 이름 sync_01…로 영상 번호를 맞춤)

3. 재생

0.00 s
출력 지연: -

소리 전환

소리: -
기기에서 영상을 재생 중일 때 "폰으로 듣기" → 같은 위치부터 폰(이어폰)으로 소리, 기기는 영상만. "기기로 듣기" → 그 위치부터 기기 스피커로

4. 지연 보정

출력 장치
추가 보정: 0 ms (+ = 영상을 늦춤, - = 영상을 당김)
